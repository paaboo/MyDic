# MyDic

Swift로 만든 macOS 메뉴바 사전입니다. macOS 14 이상과 Xcode의 Swift 도구가 필요합니다.

## 빌드 및 실행

```sh
./Scripts/build-app.sh
open dist/MyDic.app
```

메뉴바의 책 아이콘을 클릭하거나 전역 단축키(기본값 `⌥⌘Space`)를 누른 뒤 검색어를 입력하고 `Enter`를 누릅니다. `⌘1`~`⌘7`은 영어부터 학술·논문까지 전환합니다. Wikipedia는 **더보기**에서 선택할 수 있습니다. 조회한 상태에서 분야를 바꾸면 같은 검색어로 다시 조회합니다.

| 분야 | 제공처 |
| --- | --- |
| 영어, 국어, 한자 | 네이버 사전 |
| 백과사전 | 한국어 위키백과 모바일 |
| 기술백과 | IBM Think 기술 설명 글을 대상으로 한 Google 검색 |
| 첨단기술용어 | TTA 정보통신용어사전 모바일 검색 |
| 학술·논문 | Google Scholar |
| Wikipedia | 영어 Wikipedia 모바일 |

조회 시 검색어는 해당 웹 서비스로 전송됩니다. 왼쪽 하단의 사전 이름을 누르면 기본 브라우저에서 현재 검색 결과나 사전 홈을 열 수 있습니다.

하단의 **설정** 또는 `⌘,`에서 **홈**, **창 크기**, **단축키**, **검색 기록**을 엽니다. 전역 단축키를 바꾸려면 **단축키 → 키 조합 입력**을 누르고 원하는 조합을 직접 누른 뒤 저장합니다. 검색창 왼쪽의 집 아이콘을 누르면 검색을 초기화하고 홈 분야로 돌아갑니다. 검색 결과는 제공처의 모바일 레이아웃으로 요청하며, 긴 페이지는 세로로 스크롤합니다.

- **웹 로그인**에서 로그인 유지를 켜면 WebKit이 사이트에서 받은 영구 쿠키를 보관합니다. 기본값은 꺼짐입니다. 네이버 로그인 팝업은 사전 페이지와 설정된 데이터 저장소를 공유합니다. **저장된 웹 데이터 삭제**로 MyDic의 영구 웹 데이터를 지울 수 있습니다.
- **자동 실행**에서 Mac에 로그인할 때 MyDic을 실행하도록 설정합니다. macOS의 승인이 필요한 경우 설정 화면에서 시스템 로그인 항목을 열 수 있습니다.
- 앱을 종료하려면 설정 첫 화면에서 **MyDic 종료**를 누릅니다.

AppKit이 메뉴바와 팝오버를, SwiftUI가 검색창을 담당합니다. 결과 조회 시에만 WebView를 만들며, 팝오버가 닫히면 결과 WebView를 해제합니다. 다시 열면 검색창에 마지막 입력이 남아 있고 검색을 다시 실행할 수 있습니다.

## 검색 기록과 MCP 연동 준비

설정의 **검색 기록**에 최근 100개 검색어를 기기에 저장합니다. 검색 항목을 누르면 해당 분야에서 다시 조회합니다. **JSON 복사**는 추후 MCP 인덱싱에 사용할 검색 기록을 클립보드에 복사합니다.

JSON의 루트는 `schemaVersion`과 `entries`입니다. 버전 1의 각 항목에는 `id`(UUID), `keyword`, `category`, `sourceURL`, `searchedAt`(ISO 8601)이 들어갑니다. 같은 분야의 같은 검색어를 다시 조회하면 기존 ID를 유지합니다.

향후 연결할 MCP 서버는 이 JSON을 입력으로 받아 `id`를 기준으로 레코드를 추가하거나 갱신할 수 있습니다. Notion 데이터베이스, Obsidian 저장소, 자체 서버의 대상과 권한은 연결 구현 시 지정합니다. 현재 검색 기록은 로컬에 저장되며 외부 인덱싱 연결은 아직 구성되지 않았습니다.
